API Documentation

REST API reference for KERNEL Auth integration.

POST/api/v1/auth/init

Initialize application session. Returns session_id for subsequent calls.

{ "owner_id": "...", "app_name": "MyApp" }

POST/api/v1/auth/login

Authenticate with username/password or license_key.

{ "session_id": "...", "username": "user", "password": "pass" }
{ "session_id": "...", "license_key": "KERNEL-XXXX" }

POST/api/v1/auth/hwid-check

Verify hardware ID against registered devices.

{ "app_id": "default", "hwid": "ABC123-DEF456" }

GET/api/v1/var/get

Fetch cloud variables. Optional ?key=name for single variable.
